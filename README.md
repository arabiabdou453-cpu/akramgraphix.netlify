## ✦ The experience

Akram Graphix is the creative portfolio of **Akram Wanisse Marref** — a Doha-based Art Director and Senior Graphic Designer. The experience is built around one idea: turn concepts into clear visual systems that make brands easier to recognize, trust and remember.

From the first introduction to the final project image, the portfolio combines a soft editorial canvas, deep teal accents, confident typography, restrained motion and carefully structured case-study presentation.


## 🚀 Run locally

Run the production-style local preview from the project folder so clean project routes and redirect rules are included:

```powershell
npx netlify-cli dev
```

Open the local URL printed by the CLI in your browser.
